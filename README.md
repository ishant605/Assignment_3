# Task_1
## Factorial Calculator in Python

## Overview
This Python script calculates the factorial of a given number using a recursive function.

## Features
- Accepts user input for a number.
- Uses recursion to compute the factorial.
- Handles the special case where `n = 0` (returns `1`).
- Displays the factorial of the entered number.

## How to Use
1. Run the script in a Python environment.
2. Enter a positive integer when prompted.
3. The program calculates and prints the factorial result.

# Task_2
## Mathematical Operations in Python

## Overview
This Python script performs three mathematical operations on a user-input number using the `math` module.

## Features
- Calculates the **natural logarithm** (`log`).
- Computes the **square root** (`sqrt`).
- Finds the **sine** (`sin`) of the number.

## How to Use
1. Run the script in a Python environment.
2. Enter a numeric value when prompted.
3. The program will display the logarithm, square root, and sine of the entered number.
